# Música (slots opcionais)

Solte os arquivos `.mp3` aqui — arquivo ausente = silêncio, nada quebra.
Convenção completa (vibe sugerida, prompts de geração): `docs/05-musica.md`.

| Arquivo | Toca em |
|---|---|
| `musica-titulo.mp3` | tela "Escolha o jogo" |
| `musica-lobby.mp3` | seleção de personagem |
| `musica-bomber.mp3` | partida de Bomber Royale |
| `musica-batata.mp3` | partida de Batata-Quente |
| `musica-partida.mp3` | fallback dos dois modos, se o específico não existir |

Loop automático — prefira faixas em *seamless loop*. Mono/128kbps basta.

## Faixas atuais

Chiptunes de **Juhani Junkala** (juhanijunkala.com), licença **CC0** — packs
["5 Chiptunes (Action)"](https://opengameart.org/content/5-chiptunes-action) e
["4 Chiptunes (Adventure)"](https://opengameart.org/content/4-chiptunes-adventure)
do OpenGameArt, convertidas para mono/128k:

- `musica-titulo.mp3` ← Title Screen (Action)
- `musica-lobby.mp3` ← Stage Select (Adventure)
- `musica-bomber.mp3` ← Level 1 (Action; alternativas: Level 2/3 no mesmo pack)
- `musica-batata.mp3` ← Stage 1 (Adventure; alternativa frenética: Boss Fight)
